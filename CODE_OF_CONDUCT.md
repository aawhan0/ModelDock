# Code of Conduct

## Our Standard

ModelDock aims to be a respectful and constructive open-source project.

Participants are expected to:

- Be respectful and professional.
- Assume good intent while discussing technical disagreements.
- Focus criticism on ideas, code, and behavior rather than people.
- Keep discussions relevant and constructive.
- Respect privacy and do not publish private information.

Unacceptable behavior includes harassment, discrimination, personal attacks, threats, deliberate disruption, sexualized attention, and publishing another person's private information without permission.

Project spaces include GitHub issues, pull requests, discussions, reviews, and project-managed chat or meeting spaces. The same expectations apply in each space.

## Enforcement

Project maintainers may remove comments, close discussions, request changes, or restrict participation when behavior violates this code of conduct. Enforcement decisions should be proportionate to the behavior and applied consistently.

To report a conduct concern, do not open a public issue. Contact the maintainers privately through the GitHub profile associated with this repository. Security vulnerabilities should instead follow the private reporting process in [SECURITY.md](SECURITY.md). Include links or dates that help identify the concern, while omitting secrets and unnecessary personal information.

Reports are handled confidentially as far as practical. Maintainers will review the report, may ask for additional context, and will communicate the next steps to the reporter when it is appropriate and safe to do so.
