## Point System

- **+10** merged PR
- **+10** meaningful feature or implementation
- **+5** tests, CI, observability, or quality improvement
- **+3** documentation or developer-experience improvement
- Points stack when a merged PR covers multiple categories.

## Want to be on the wall?

Pick an open issue, follow the contribution guidelines, and open a focused pull request. Every accepted community contribution gets recognized here.

Thank you to everyone who takes the time to improve ModelDock. 🚀
