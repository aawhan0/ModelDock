# ModelDock

ModelDock is a self-hostable AI/ML model serving and inference platform for managing the lifecycle of machine-learning models from registration and evaluation to deployment, inference, benchmarking, and monitoring.

## Focus

- Model registry and versioning
- Model evaluation and comparison
- Production-style inference APIs
- Inference performance benchmarking
- Monitoring and observability
- Dockerized, local-first deployment

## Tech Stack

**FastAPI · Python · PyTorch · Hugging Face · PostgreSQL · Redis · Next.js · TypeScript · Docker · Prometheus**

## Goal

Build a practical MLOps platform that demonstrates how a trained model becomes a reliable, measurable production inference service.

> Built as part of a Full-Stack AI Engineer portfolio.
